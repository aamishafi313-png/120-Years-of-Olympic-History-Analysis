🏅 120 Years of Olympic Games Analysis

📌 Project Overview

The 120 Years of Olympic Games Analysis project explores historical Olympic athlete and medal data to uncover meaningful insights into Olympic participation, medal achievements, gender representation, and country-wise performance.

This project uses Microsoft Excel for data cleaning and preprocessing and Microsoft Power BI for data modeling, DAX calculations, interactive visualizations, and dashboard development.

The goal is to transform historical Olympic data into meaningful insights through interactive dashboards and data-driven analysis.

🎯 Project Objectives

- Analyze Olympic Games data across different years.
- Identify countries with the highest medal achievements.
- Compare Gold, Silver, and Bronze medal distributions.
- Analyze male and female athlete participation and medal achievements.
- Explore athlete performance across sports and events.
- Identify trends in Olympic participation over time.
- Build interactive dashboards for exploring historical Olympic data.

🛠️ Tools and Technologies

- Microsoft Excel — Data cleaning, preprocessing, lookup functions, sorting, filtering, and PivotTables.
- Power Query — Data transformation and preparation.
- Microsoft Power BI — Data modelling and interactive dashboard development.
- DAX (Data Analysis Expressions) — Measures, KPIs, and analytical calculations.
- Data Visualization — Charts, slicers, drill-through, drill-down, and interactive reports.
